# 英语背诵打卡 v7.5 学习体验版

基于 v7.4 继续升级，保留腾讯云、教师/学生登录、听障语音转文字、单词学习/拼写、积分、次数审批、闭眼检测等现有功能。

新增：
1. 错词本
   - 学生拼写错误自动累计
   - 学生端按错误次数查看错词
   - 支持直接练习错词
   - 教师端显示高频错词汇总

2. 分段背诵
   - 教师创建/编辑课文时可按句号或换行自动分段
   - 可逐段修改
   - 学生端可选择某一段练习，也可全文背诵
   - 旧课文任务自动兼容为单段/全文

3. 背诵结果逐词反馈
   - 绿色：正确
   - 红色：漏读
   - 黄色：多读
   - 蓝色：错词/替换

说明：
- 当前错词本使用浏览器本地存储保存；后续若需要“学生跨设备错词同步 + 教师端全设备汇总”，建议继续扩展腾讯云后端数据结构。
