# 英语背诵打卡 v8.1 家庭多学生版

基于 v8.0 升级：

## 学生登录入口更简洁
- 当前设备已有有效学生登录时，不显示 ID + 密码入口
- 只有以下情况显示登录框：
  - 设备从未登录过任何学生
  - 某学生 30 天 token 已过期
  - 主动点击“添加其他学生”

## 同设备多学生
- 一个设备可记住多个学生
- 每个学生保存：学生 ID、姓名、班级、30 天 token
- 不保存明文密码
- “切换学生”可直接在已记住学生间切换
- 某一个学生 token 过期，只要求那个学生重新登录，不影响其他学生

## 账号管理
- 退出当前学生：只退出当前界面，保留该学生免密凭证
- 从本设备移除此学生：只删除本设备上的记忆，不删除云端学生与学习记录
- 清除此设备全部学生账号：清空本机所有学生登录记忆
- 添加其他学生：临时显示 ID + 密码登录框，成功后加入家庭学生列表

后端仍使用“腾讯云 SCF v7.5 兼容 v8.0”，无需修改。
