# 英语背诵打卡 v6.3（登录会话一次校准版）

本版修改了活体/眼睛校准生命周期。

## 新规则
每次学生登录后，只需要完成一次：
1. 打开摄像头
2. 活体检测
3. 睁眼约1秒
4. 闭眼约2秒
5. 校准通过

校准通过后，本次登录会话内：
- 换任务不再重复活体检测
- 换任务不再重复睁眼/闭眼校准
- 每次背诵提交后仍自动关闭摄像头
- 下一次点击“开始背诵/背单词”时，自动重新打开摄像头
- 自动沿用本次登录已经完成的个人眼睛校准
- 每一次新的背诵尝试，睁眼累计时间都重新从 0 秒开始

## 什么时候需要重新做活体和校准
- 重新登录
- 页面刷新/重新打开
- 手动关闭并重置验证（如后续增加该操作）

## 保留 v6.2 修复
麦克风权限真正启动之前，不开始累计睁眼时间，也不占用背诵次数。
