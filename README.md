# 英语背诵打卡 v8.0 学生学习首页版

核心变化：

1. 学生账号界面
- 同设备自动登录后直接显示“欢迎回来”
- 自动登录状态下隐藏登录框、首次注册/重置密码区域、忘记密码区域
- 未注册或老师批准重置时，登录失败会自动展开“首次注册 / 重置后设置密码”
- 正常未登录时仅保留一个小按钮用于手动展开注册区域

2. 单词与课文彻底拆开
- 📚 单词学习：单词列表、中文、发音、拼写练习、错词本
- 📖 课文背诵：分段/全文、活体、闭眼检测、语音评分
- 课文下拉只显示课文任务；单词下拉只显示单词任务

3. 单词正式测试
- 平时拼写练习不限次数、不计积分
- 正式测试逐题只显示中文，可播放发音
- 测试过程中不显示对错，完成后统一公布结果
- >=80% 合格，任务获得 1 分
- 默认 3 次正式测试机会，用完可申请老师增加次数
- 错题自动进入错词本
- 使用现有 /student/attempt 接口，因此无需修改 SCF 后端

4. 积分拆分显示
- 总积分
- 单词测试积分
- 课文背诵积分

5. 教师任务列表
- 按“单词任务 / 课文任务”分组显示

SCF 后端继续使用 v7.5 教师信任设备版，无需再次修改。
